- addresses are used frequently in java.net APIs as host identifiers, or socket endpoint identifiers

- The INetAddress class is the abstraction for IP addresses
    - Inet4Address for IPv4
    - Inet6Address for IPv6

- most cases, there is no need to deal directly with the subclasses

- two main entities, client and server
    - communicate via network sockets
